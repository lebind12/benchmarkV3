# 외부 기사 입력·팀/선수 연결 — v1

2026-10-28 사용자 확정: FULL, 외부 기사 텍스트 붙여넣기와 출처 URL, STREAMER/ADMIN 전용.

## 목표와 흐름
관리자가 기사 텍스트와 출처 URL을 입력하고 분석 버튼을 누른다. LLM이 언급을 추출하고 서버가 실제 DB 후보와 원문 근거를 검증하여 팀·선수 상세 링크를 보여준다. 모호한 대상은 보류한다. 결과는 현재 화면에만 유지하고 공개 뉴스 등록·분석 이력 저장은 하지 않는다. 새로고침하면 사라짐을 안내한다.

## 범위
입력/분석/근거/상세 이동, 입력 검증, 서버 STREAMER/ADMIN 권한, 중복 요청 방지·시간 제한·제한된 외부 호출, 결과 없음/보류/실패 구분. URL은 출처 표시 전용이고 fetch하지 않는다. 자동 RSS 처리, 백필, 사건 분류/필터, 공개 발행, 뉴스·이름 번역 변경, DB migration, 새로운 워커는 제외한다. 일반 페이지 DB 조회 정책은 유지한다.

## 기술 선택
기존 Google 인증 패턴을 사용하는 별도 Vertex 뉴스 어댑터. 모델 설정은 뉴스 전용이며 기본 후보는 현재 프로젝트 사용 모델 gemini-3.5-flash, global. 구조화 JSON으로 추출하고 서버가 원문 부분문자열과 DB 후보를 재검증한다. 전체 후보나 사용자 원문을 로그에 남기지 않는다. 기존 단순 matcher는 후보 생성 참고이며 확정 근거가 아니다. DB 이름/번역명의 명백한 일치만 연결하며 동명이인·단독 성은 보류한다. 임의 URL/ID를 LLM으로 만들지 않는다. 실제 모델 품질은 유료 실호출을 하지 않은 테스트와 구분한다.

기술 조사 및 운영 검토: 관리 checkout docs/ax/news-context/research.md. 기존 조사 중 자동 수집/백필 권고는 이번 범위에서 폐기한다. 기획 검토 news_plan_review의 수동 MVP 검토 수용. 공식 구조화 출력 근거: https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output

## 화면 방향
기존 관리 화면의 색상/타이포 토큰 유지. 데스크톱은 왼쪽 입력, 오른쪽 연결 근거; 모바일은 세로 배치. 장식보다 기사 구절과 대상 연결 관계를 강조한다. 폼 라벨, 키보드 포커스, 상태 안내를 제공한다. 목업 시 가상 예시임을 명시하고 실제 AI 분석처럼 표시하지 않는다.

## 수용 기준
- AC-1: STREAMER/ADMIN만 화면과 API 사용. 비로그인·USER·비활성 계정 거부.
- AC-2: 기사 텍스트+HTTP(S) 출처 URL 유효성·길이 제한, 빈 입력 오류.
- AC-3: 실제 DB 후보 및 원문 근거를 검증한 대상만 연결. 동명이인·후보 없음 보류.
- AC-4: 연결마다 입력 원문 근거와 DB 상세 경로, 출처 링크 표시. 출처 내용 검증으로 오인하지 않게 안내.
- AC-5: 분석중/완료/없음/보류/실패 구분, 실패 입력 보존·재시도.
- AC-6: 중복 클릭 방지, 입력 변경 후 늦은 응답 무시, 이전 입력 결과와 혼동 방지.
- AC-7: URL fetch 없음, 기사 명령문은 데이터, HTML 실행 없음, 전문 로그 없음. 외부 호출 제한·timeout.
- AC-8: 공개 뉴스와 DB를 변경하지 않음. 기존 뉴스·팀/선수 상세 회귀 없음.

## 순서와 책임
프론트 목업+endpoint 계약 → 운영자 계약 확인 → 백엔드 분석 API+프론트 실연결 → 별도 behavior-tester → 운영자 코드/결과 검토. 개발 소유 범위는 work-brief.json으로 지정한다. 전용 codex/news-context worktree에서만 제품 수정. 관리/메인/AX checkout 보호. 원격 push·배포·운영 DB 변경 금지. 검증된 개발 커밋은 별도 통합 브랜치에 운영자가 병합하여 원본 checkout을 보호한다.

## 검증 한계 및 성과
단위/통합 테스트의 모델 stub과 실제 Vertex 호출을 구분한다. 자동 정확도/비용 성과를 주장하지 않는다. 서비스 전체 포트폴리오 근거에 계획·화면·테스트를 남긴다.
