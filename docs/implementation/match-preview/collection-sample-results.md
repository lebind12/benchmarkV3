기술적 생성·저장·재조회 확인은 **4 / 4 경기**다. 본문5개가 모두 있는 경기는 팰리스–리버풀·첼시–리즈이며, 다른 두 경기는 아래의 선택 섹션이 비어 있다. **사용자는 미래 본문과 다른 대진 기술 시험을 통과 처리했다**(2026-11-13 04:02 KST 기록). 특히 12월6일 맨유–코번트리 결과를 자료가 부족한 미래 경기의 최소 내용 구성 사례로 수용했다. 수집 연결은 다음 구현 단위이며 이번 결과를 운영 수집 연동 성공이라고 표시하지 않는다.

## 실행 범위

기존 관리자 `previewRunsApi.fixture`로 네 경기의 저장 자료와 selectable=true를 확인했다. 생성은 같은 클라이언트의 `runBundle`이 보내는 기존 `POST /api/v1/admin/preview/bundle-runs`(fixture_id, mode=live)를 사용한다. 새 생성 스크립트나 검증 도구를 만들지 않는다. API 최신 자료를 운영 테이블에 반영하는 수집 작업은 이번 실행이 아니다.

과거 경기는 현재 확보 가능한 자료로 기술 동작을 확인하며 경기 전 당시 정보만의 복원으로 표시하지 않는다. 기존 모듈 재시도 후 정상 생성도 성공으로 판단한다. 생성 요청의 응답이 불명확하면 저장된 실행부터 확인하고 요청을 중복 전송하지 않는다.

### 맨유–본머스 결과

저장된 실행 조회의 최종 상태는 live/dev/succeeded, quality=ready다. 제품 모델 표기는 `gemini-3.5-flash`이며 이번 작업에서 모델 설정을 변경하지 않았다. 실제 모델 전송7회이며 R2(부상)의 첫 시도 rate_limited 오류 뒤 두 번째 시도에서 복구했다. retry_count=1이며 이 복구를 경기 생성 실패로 세지 않는다.

- 저장 섹션5행: AI 전망·선수·부상·매체 본문4개, 배당은 빈 본문과 unavailable_reason을 저장했다. 예상점수는 1–2다.
- 배당 진단은 “제공자가 이 경기의 배당 자료를 반환하지 않았습니다.”이며 제공자 보충 조회1회가 기록돼 있다. `provider_odds.py`의 예외·봉투 오류·provider errors 분기와 구분된 `envelope.empty` 분기에서 이 문구가 나온다. 이 근거로 현 호출의 빈 응답 처리로 분류하며, 별도 원시 HTTP 응답 본문을 직접 확인했다고 보고하지 않는다. 과거 배당이 다른 경로에도 전혀 없다는 뜻은 아니다.
- 관리자 저장 결과를 다시 열어 AI 전망·예상점수1:2·주목4명·부상4명·매체3개가 표시됨을 확인했다. 선수 사진7개와 팀 로고4개의 로드를 확인했으며 우가르테 사진은 없었다. 사진 없음의 자료/이름 연결 원인은 아직 판정하지 않았다.
- 주목 선수4명 내부 ID는 저장돼 있다. 이름 해석기 미주입 진단이 함께 있지만 표시된 사진·한글이 모두 없다는 결론으로 확대하지 않는다.
- 원문 주장 자체의 사실성·과거 당시 정보 복원은 이 기술 결과의 자동 성공 판정에 포함하지 않는다.

## 사용자 수용과 후속 관측

1. 미래 내용은 사용자 통과를 받았다. 12월6일 결과를 최소 구성 사례로 삼되 자동 길이·품질 점수 문턱으로 바꾸지 않는다. 현재 기술 시험의 수용은 완료다.
2. 사진이 없던 부상5명(우가르테·주앙 페드로·마테오 조셉·세스코·하지 라이트)은 저장 JSON에서도 player_id=null임을 확인했다. 다른 부상 행의 ID와 사진은 존재한다. 사용자의 방향에 따라 이름 검색과 DB 내부 ID·한글/사진 연결을 후속 구조화 단계에서 다룬다. 정확한 미연결 원인은 아직 미확정이며 이번에 수정한 것은 아니다.
3. 팰리스–리버풀의 매체 예상점수 제거 진단과 본문 잔존, 출처 링크 누락은 후속 관측으로 남긴다. 기술 시험 통과를 이 문제의 수정 완료나 본문 개별 주장의 사실 확인으로 확대하지 않는다. 사진·매체 보완은 PC-CONNECT의 선행 조건이 아니다.

이번 범위에서 제품·테스트 코드 수정, 승인 POST, 새 수집 실행, 운영 배포는 하지 않았다. 실제 모델 생성·새 preview_dev 실행 저장은 위4경기에 한해 수행했다. 원래 홈의 맨체스터 시티–풀럼 승인본은 변경하지 않았다.
