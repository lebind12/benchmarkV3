# trace: retain-on-failure 가 실패 아티팩트에 로그인 비밀번호를 남기는지 재현

합성 카나리(ENVCANARY_9f2b7d)를 환경변수로만 넘기고, 로그인 화면에서 그 값을
비밀번호로 입력한 뒤 일부러 실패시켰다. 출력 디렉터리는 저장소 밖 /tmp 였다.
실제 자격 증명은 쓰지 않았다.

## trace: 'retain-on-failure'
artifacts: .last-run.json, test-failed-1.png, error-context.md, trace.zip
- trace.zip            : 카나리 7회 발견  <-- LEAK
- error-context.md     : 카나리 0회
- test-failed-1.png    : 카나리 0회

## trace: 'off' (수정 후)
- test-failed-1.png    : 카나리 0회
- error-context.md     : 카나리 0회
- trace.zip            : 생성되지 않음

## 결론
누출 경로는 trace 캡처였다. 소스에 하드코딩된 문자열이 아티팩트에 남는 것이 아니라,
trace가 실제 POST 본문을 압축 해제 가능한 형태로 저장한다. 그래서 trace를 끄고,
`npm run test:e2e:artifact-safety`로 실제 아티팩트를 매번 검사한다.
그 검사는 trace를 다시 켜면 LEAK으로 실패하는 것까지 확인했다(같은 세션에서 1회 재현).
