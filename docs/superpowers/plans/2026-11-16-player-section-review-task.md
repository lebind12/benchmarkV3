# NS-00 독립 계약 검토 배정

먼저 `/Users/woolee/benchmark/.agents/skills/poteto-mode/SKILL.md` 전문을 읽고 적용하라. 착수 보고에 읽은 경로와 적용할 원칙을 적고, 완료 보고에 실제 읽기 기록과 판단에 미친 영향을 남겨라.

사용자가 이번 선수 섹션 개발의 모든 DeepSeek 호출을 Gemini Hydrogen으로 대체하라고 명시했다. 이번 작업에서는 기존 AGENTS.md의 DeepSeek 제한에 대한 사용자 예외가 적용된다. 너는 별도 독립 검토자이며 실제 모델은 `gemini-4-hydrogen-high`, Orca agent는 `antigravity`다. 다른 모델로 바꾸거나 하위 워커를 만들지 않는다. 모델이 다르면 구현/검토를 중단하고 보고한다. GPT 조정자가 전체 계획을 관리한다.

검토 대상은 `/Users/woolee/benchmark/docs/superpowers/plans/2026-11-16-player-section-storage.md`와 그 문서가 가리키는 기존 소스의 관련 계약이다. 현재 main HEAD에는 미커밋 제품 변경이 다수 있으므로 현재 디스크 파일을 읽고 HEAD만 보지 않는다. 사용자 결정은 계획 §1에 확정되어 있다. 고정 네 자리/본문 보존/기존 DB 읽기 전용/preview_dev 쓰기/한 번 섹션 재생성/최종 중복 하나 유지/B 기존 UI 검사 요구를 다시 뒤집지 않는다.

소스와 문서 모두 읽기 전용이다. 제품 코드, 문서, 테스트, 설정, DB를 수정하지 않는다. 검토 결과는 Orca 완료 메시지로 전달한다. 새 검증 코드나 재현 스크립트를 작성하지 않는다. 현재 범위를 넘는 전면 감사와 실제 모델/DB 생성 호출은 금지한다.

NS-00의 미결정 계약에 대한 가장 작은 구현 가능한 권고를 제출하라. 특히 다음을 현재 소스 근거와 함께 확인한다.

- 새 섹션 결과 ID와 run_id, 내부/외부 선수 ID, 고정 자리와 빈 자리의 의미.
- 기존 한글명 우선순위, AI 번역 후보의 실행별 소유권, 동시 저장과 undo. 현 단계에서는 실행별 후보 스냅샷을 사용하고 실행 간 자동 공유를 하지 않는 단순한 계약이 요구를 충족하는지 검토하라. 검수 UI는 후순위다.
- 누락/중복 검증이 기존 조기 필터링 전에 적용되고 마지막 응답만 사용하는지, 기존 실제 전송 상한 3회와 내용 재생성 1회의 결합 가능성.
- A 저장과 B 생성/기존 검사 UI 파일 경계, C 통합과 기존 프리뷰 보존·승인 버전 선택.
- 데이터 손실/잘못된 연결/실제 수용 기준 누락이 있는지. 참고 개선은 차단 항목과 분리한다.

완료 보고는 요구사항 위반·현재 범위 결함·미결정 계약 권고·참고 개선을 구분하고 파일/함수 근거를 남긴다. 독립 검토는 이번 1회이며 후속 수정 확인은 지적한 부분만 한다. 테스트 개수나 범용성 확대는 목표가 아니다. 비밀값·계정 정보는 출력하지 않는다. Plans.md는 조정자만 수정한다.
