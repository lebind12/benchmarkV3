# 관리 목업 — 요구사항 명세

상위: [요구사항](streamer-management-mock.md). 단계: FE 목업 평가, 서버 기능 구현 전.

## 범위와 경계

- 개발 또는 명시적 mock 모드에서 `/admin/mock` 제공. 별도 로그인 없이 샘플 작업을 평가한다. `/admin`의 기존 권한과 동작은 유지하고 authUser/mockRole을 변경하지 않는다.
- `수집 대상 / 수집 실행 / 실행 이력 / 번역 검수` 네 탭. query `tab=targets|execution|history|translations` 유지. 누락/잘못된 값은 targets로 정상화한다.
- 상단에 `평가용 목업` 및 `변경은 샘플 데이터에만 적용됩니다` 표시. 서비스 공통 설정이라는 향후 제품 안내도 구분해 표시한다. 실행 중 작업 바로가기, 샘플 초기화 제공.
- 화면은 MSW 전용 `/api/_mock/management/*`에 fetch한다. 실제 관리 API·외부 API·DB·AI·Redis 호출은 없다. 상태는 목업 전용 key에 보존한다.

## 수집 대상

- 목록은 대회/국가/시즌, 활성, 상세·선수·순위 옵션, 제한, 최초/마지막 수집 상태를 표시한다. 검색(한/영 이름·ID)과 활성 상태 필터, 선택 체크박스 제공.
- 추가 패널: 샘플 카탈로그 검색→리그→지원 시즌 선택. 허용 시즌은 각 리그의 최신 두 실제 개최 시즌. 월드컵 샘플이면 2026/2022처럼 연속 연도 가정 금지. 지원하지 않는 영역은 설명하고 비활성화한다.
- 편집: 현재 값을 채우고 기존 리그/시즌 identity를 보여준다. 제한 값 양의 정수 또는 비워 null. 저장은 같은 리그/시즌이면 기존 항목 갱신. 잘못된 제한·시즌은 필드 오류, 입력 보존.
- 활성 변경·제외 전 영향 설명. 제외는 설정만 제거, 이미 적재한 데이터 보존. 제외 확인 dialog와 취소 제공.
- 선택 실행은 선택 ID를 유지해 execution 탭 이동. 비활성 대상은 선택 실행에서 제외/활성화 필요를 명시한다. 목록 0건/검색 0건/로드 실패·재시도를 구분한다.

## 수집 실행

- 대상 선택·initial(최초 전체)/refresh(갱신) 설명·옵션 snapshot·공통 영향·실행 확인 제공. 미선택/비활성/기존 진행 작업이 있으면 실행하지 않고 안내한다.
- 확인 후 샘플 run 생성. 준비/진행률·현재 단계·대상별 처리 수·저장/실패/미처리·한국어 로그를 표시한다. 동일 화면에서 실패·취소·완료 결과를 읽을 수 있다.
- 모의 진행은 경과 시간 기반으로 동작하고 목업 GET으로 갱신한다. 약 20~40초 내 완료되며 진행 중 취소 가능. UI polling은 mount/active run 동안만, 이탈 시 종료한다.
- 취소는 cancel_requested와 cancelled 표현, 이미 저장된 데이터 유지/남은 미처리를 표시. 부분 실패·중단 샘플도 평가할 수 있게 한다.
- 새로고침/재진입은 저장된 run ID/상태로 복원. 모의 서버 프로세스 복구를 실제 구현했다고 표현하지 않는다.
- 성공/부분 실패/취소/실패/중단을 이력에 연결한다. 실패 재실행은 실패 대상만 선택한 실행 확인 화면을 열고 parent ID 연결한다. 버튼 클릭만으로 즉시 재실행하지 않는다.

## 실행 이력

- 최근 7일 종료 작업 목록, 날짜/상태/이름 검색, 실행자·시작/종료·모드·대상 수·결과 표시. 진행 중 작업은 execution으로 안내한다.
- 상세 패널/다이얼로그는 대상별 결과, 저장/실패/미처리, 로그, 상위/재실행 연결과 7일 보관을 표시한다. 원시 JSON 덤프 대신 표와 사용자용 문구.
- 부분 실패/실패/중단 등 재시도 가능한 작업은 대상 선택을 execution으로 전달. 정상 0건/필터 0건/조회 실패 구분.

## 번역 검수

- 리그/팀/선수/감독 유형 선택, 원문·한국어 이름/짧은 이름 검색, 전체/번역/미번역 필터(한국어 이름 유무로 판단, 짧은 이름은 선택). 동명이인 식별용 ID·팀 등 샘플 맥락 제공.
- 편집은 원문 읽기 전용, 한국어 두 필드, 번역/미번역 자동 표시, version·수정자/시각·보호 안내. 공백을 null로 저장하면 원문 fallback되며 사람 수정 보호를 유지한다.
- 저장 payload는 expected_version. 409 시 편집 입력을 보존하며 서버 최신값과 내 값을 비교한다. 최신 버전을 불러와 재검토 후 명시적으로 다시 저장. 충돌을 무시하고 덮어쓰는 버튼은 제공하지 않는다.
- 변경 이력은 수정자/시각·이전/이후 두 필드를 표시. 수정 없이 원문 변경/가짜 자동번역 결과를 만들지 않는다.

## 평가 시나리오와 피드백

- 작은 `화면 상태 살펴보기` 영역에서 정상/빈 결과/로드 오류/실행 부분 실패/프로세스 중단/번역 충돌을 재현할 수 있다. 데이터 초기화와 상태 재현은 실제 서비스 동작으로 표시하지 않는다.
- 정상 화면이 기본값이다. 상태 재현을 해제하면 정상 데이터로 복귀 가능해야 한다.
- 저장/실행 성공은 명확한 피드백. 오류는 재시도 또는 입력 수정 경로를 주고 제출 입력은 보존한다.

## 접근성·반응형

- 기존 Pretendard·light/dark 토큰과 파랑 주요 조작색을 활용한다. 데이터로 계산한 요약만 표시하며 실제 운영 수치처럼 보이지 않게 한다.
- 키보드 탭/Enter, 선택 상태, 명시적 label, 상태 알림과 progress 접근성. dialog는 modal·Escape·초기 포커스·포커스 복귀/가두기.
- 페이지는 header 아래 세로 scroll. 1440/1280과 390px에서 평가. 모바일 탭은 넘겨 볼 수 있고 편집 패널은 한 열로 표시, 긴 표는 내부 scroll. body 전체 가로 넘침 금지.
- 로고는 생성하지 않는다. 텍스트/일반 대회 아이콘으로 샘플 identity를 표시할 수 있다.

## 수락 기준

네 탭의 주요 동작과 오류/빈/충돌을 직접 평가할 수 있고, reload 복원·초기화·실행 취소가 재현되며 실제 API 요청이 발생하지 않는다. BE lifecycle/실 인증/DB 저장/배포 완료로 보고하지 않는다.

## 2026-10-25 사용자 평가 반영

- 카탈로그는 수집 대상 목록 위 독립 영역. 이름/국가·리그 ID → DB 조회 → 리그별 최신 두 개최 시즌 버튼 → 신규 설정 또는 등록된 설정 편집. 기존 `/admin`의 조회/최신화 분리를 유지한다.
- 최신화 확인 → 중복 클릭 차단/진행 표시 → 확인/저장/DB 전체 건수와 마지막 최신화 시각 → 기존 검색 조건 재조회. 실제 외부 호출은 없으며 목록 변경 없는 샘플임을 표시한다. 최신화와 경기 수집/대상 등록은 별개다.
- 실패/부분 실패 이력은 `실패 로그 보기`로 진입하며 오류 수준으로 기본 필터. 대상·시즌·단계·시도 횟수·한국어 설명/조치와 원문을 함께 제공한다.
- 이력 필터에 해당하는 작업의 원인별 오류/재시도·경고 발생 수, 영향 작업/작업별 대상 수를 표시한다. 상세에서 원인별 로그로 좁힌다. 실패 데이터 건수와 로그 발생 건수를 구분한다.
- 모르는 원인은 미분류, 수준도 없는 기존 원문은 원인 통계에서 제외한다. 새 구조화 코드와 제한적으로 인식한 과거 패턴만 한국어로 대응한다. 원문은 보존하며 생성형 AI 번역을 호출하지 않는다.
- 검수 완료/미검수 체크와 `reviewed` 저장 필드는 제거한다. 사람 수정 보호·수정 이력·동시 수정 충돌은 유지한다.
