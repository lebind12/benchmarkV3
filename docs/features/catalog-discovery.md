# 관리 카탈로그 탐색 개선 — 2026-10-25

## 화면·계약 (FE 먼저)

기존 관리 패널/서체/색상을 유지한다. 검색 영역을 넓게 두고 추천 목록에서 로고·한글명·원문·국가·종류·등록 여부를 비교한다. 국가대표/아시아/클럽 컵 바로가기는 검증된 주요 대회를 묶는 보조 탐색이며 전체 대회의 완전한 지역 분류를 의미하지 않는다. ID는 상세 검색으로 옮긴다.

- 검색창 focus: DB에 존재하는 주요 대회 추천. 입력: 250ms 후 한글·별칭·영문 자동완성. ↑↓/Enter 선택, Escape 닫기. 후보 선택은 해당 대회 결과를 표시하며 시즌 선택만 편집기로 연결한다. 등록/수집은 별도 명시 행동이다.
- 국가/국제대회 및 League/Cup 필터, 주요 대회 바로가기, 결과 수·페이지·전체 초기화. 입력/필터 변경 시 첫 페이지·선택 ID 해제. 늦은 응답은 무시하고 로딩 중 옛 후보를 선택하지 못한다.
- 한국어명은 기존 사람 수정 번역 우선, 없으면 확인된 대회의 기본 표기, 나머지는 원문. 한글 이름/약칭 검색도 유지한다. 원문은 항상 표시한다. 여자/연령 구분은 확인된 표기 또는 원문으로 제시하며 알 수 없는 구분은 만들지 않는다.
- 최신화 확인/진행/결과/현재 조건 재조회 유지. 수집 제외는 데이터 삭제가 아니다. 자동 종료/기간 제한 수집/날짜 기반 진행 중 표시는 이번 범위에 추가하지 않는다.

GET `/api/v1/admin/management/catalog`

query / id(양수; 기존처럼 검색어보다 우선) / country(원본 국가 값) / type(League|Cup) / group(national|asia|club) / page(>=1) / page_size(1..100; 기본100).

응답: `{items:[{id,name,name_en,logo_url,country,country_label,type,aliases,featured,seasons,standings}], total(조건 일치),catalog_total,page,page_size,countries:[{value,label}],updated_at}`. 기존 필드를 보존하며 country 원본 식별자는 유지한다. 번역 목록과 검색 조건은 서버에서 처리하고 페이지 적용 전 필터/집계한다.

## 데이터 근거·운영

실제 연결 DB를 읽기 전용 조회해 ID/원문 확인: 7 Asian Cup, 23 EAFF E-1 Football Championship, 803 Asian Games, 897 Asian Cup Women, 1188 EAFF E-1 Football Championship - Women, 532 AFC U23 Asian Cup, 965 AFC U20 Asian Cup, 1012 AFC U17 Asian Cup 등. `app/data/catalog_discovery.json`은 검색 별칭/기본 표기이며 원본과 번역 테이블을 변경하지 않는다. 실제 row가 존재하고 원문이 일치할 때만 적용한다. 대회별 지원 시즌은 카탈로그의 최신 2개 실제 개최 시즌을 그대로 사용한다. AI/외부 API 호출 없는 DB 조회다.

FE mock과 계약 → 실제 API 구현/연동 → 격리 DB·목업/실 API 브라우저 검증 순서. schema/migration/운영 DB 쓰기/서비스 재시작/배포 없음. 기존 미커밋 변경 및 브랜치를 보존한다.

## 구현·검증 결과

- 공통 CatalogPanel에 추천/자동완성·키보드 선택·등록 표시·국가/종류·주요 대회·상세 ID·페이지 처리를 구현하고 실제 API와 평가 목업을 연결했다. 자동완성은 최대 6개, 결과는 페이지당 20개다. 후보 선택 자체가 저장/수집을 실행하지 않는다.
- 기존 LeagueTranslation을 external ID로 연결해 사람 수정 이름/짧은 이름 검색을 지원한다. 사람이 의도적으로 이름을 비웠으면 기본 한국어명을 다시 끼워 넣지 않고 원문을 표시한다. 신규 별칭은 DB 원본과 번역을 갱신하지 않는 검색 메타데이터다.
- 실제 기존 연결 DB 읽기 전용 검증에서 아시/동아시아/EPL의 결과와 API 시즌 표기를 확인했다. API의 시즌 연도와 실제 개최 연도가 다를 수 있으므로 연도를 임의 교정하지 않는다. 영어 1~4자 검색은 단어 시작과 별칭을 사용해 EPL이 League Play-offs 중간 문자열에 잘못 걸리지 않도록 했다.
- 신규 DB 테스트 5개 + 기존 관리 7개 + 소속 조건 3개 = **15개 통과**. 한글/별칭·동명 국가·종류/그룹·ID 우선과 필터 교집합·번역 우선/의도적 NULL·125건 페이지/중복 없음·파라미터 제한/권한을 확인했다.
- 관련 FE unit **36개 통과**. 늦은 검색 응답 무시·debounce 중 기존 후보 제거·오류 후 검색어 보존/재시도를 포함한다.
- 목업 브라우저 **16개**, 실제 Vue→FastAPI→격리 PostgreSQL 브라우저 **7개** 통과. 이벤트 대회 검색→시즌→편집, 키보드·조건 해제·여자 구분·빈 결과·모바일 390px 가로 넘침 및 기존 수집/로그/번역 기능을 확인했다. 외부 API-Football과 Upstash는 테스트 fixture로 대체한다.
- TypeScript/Vite build·변경 Python Ruff·diff 공백 점검 통과. 화면 확인: `out/management-mock/catalog-mobile.png`.
- 운영 DB는 읽기만 수행했고 migration/운영 설정/배포를 실행하지 않았다. 기존 5173/8000 개발 서버는 유지하고 별도 8016 fixture 서버만 검증용으로 다시 실행했다. 기존 로컬 계정은 `/admin?tab=targets`, 샘플 UI는 `/admin/mock?tab=targets`에서 확인한다.

## 국가 검색·한국어 우선 정렬 후속

사용자 요청에 따라 국가·지역 조건을 검색형 추천 선택으로 변경한다. FE는 기존 팀 선택 컴포넌트의 키보드/팝업 위치 처리를 재사용하고 국가에서는 로고 없이 한국어 표시명·원본 국가명을 비교한다. 입력 전 한국어 표기 항목 우선 추천, 입력 중 한국어/원문 필터, 선택/전체 해제·Escape/키보드 선택을 제공한다. API의 기존 countries `{value,label}` 및 country 원본 식별자는 유지한다. 대회 결과도 실제 표시명에 한국어가 있는 항목을 페이지 처리 전 우선하며, 그 안에서 정확한 별칭·기존 주요 대회 순서를 적용한다. 사람이 비운 한국어명은 원문 fallback으로 정렬한다. 기존 번역 및 원본 DB 변경·AI 호출·배포는 없다.

국가 검색 후속 검증 완료: 한국어/영문 및 한국→대한민국 검색, 전체 해제, 빈 추천·Escape 포커스 복귀, 390px 메뉴 배치, 기존 팀 로고 유지 확인. 국가별 원본 식별자는 바꾸지 않는다. 국가 목록은 한국어 표기 우선/가나다순, 대회는 한국어 표시명 우선→정확한 별칭→기존 주요 대회 순서다. 한국어 정렬은 DB 페이지 처리 전에 적용됨을 테스트했다. 격리 PG 16개·관련 FE unit 37개·목업 E2E 17개·실 API E2E 7개·build/Ruff 통과. 화면: `out/management-mock/catalog-country-mobile.png`. 이번 후속도 schema/운영 DB 변경·배포 없음.
