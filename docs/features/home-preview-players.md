# 주요 선수·기록과 사진 카드 — 2026-10-25

## 사용자 확정

관전 포인트에 주요 선수와 이어가는 기록을 포함한다. 부상·퇴장/출전 변수는 경기 영향과 함께 비교적 알려진 선수의 인지도를 보조 기준으로 고려하되 팀당 최대 2명/합계 4명이다. 홈/원정 열을 고정한 2×2 카드로 배치하며 모바일에도 두 열을 유지한다. 각 카드 우측에 사진을 표시한다. 눈여겨볼 선수는 독립된 섹션에서 이름·사진·주목 유형을 기본 표시하고 ‘선정 이유와 기록 보기’를 펼쳐 이유와 현재 확인된 기록을 본다.

## 근거와 모델 경계

- 부상 후보의 `importance_evidence.recognition_name`은 DB에 확인된 선수 정식 이름이다. 기존 출전 수치 기준에 더해 cutoff 이전 DB 선수 identity가 확인되면 후보로 검토할 수 있다. LLM은 인지도를 순위의 보조 판단에 사용하지만 수상/이적료/전술/포지션/부상 기간 등을 모델 지식으로 사실처럼 추가하지 않는다. 상태 충돌은 계속 제외한다. 시즌·최근 출전 수치와 선정 근거 문장은 서버가 조립한다.
- `facts.player_spotlights`는 DB의 해당 대회·시즌 선수 기록, 선수 identity, 최대 최근 10개 완료 팀 경기의 players payload에서 조립한다. 현재 팀이 다른 것으로 확인된 선수 및 확정 결장·상태 충돌 선수는 후보에서 제외한다. team별 최대 4명/합계 8명 입력을 제공하고 기존 analysis 호출이 `analysis.player_watchpoints`를 팀당 최대 2명/합계 4명 선택한다.
- 시즌 goals/assists/appearances/minutes는 원래 NULL을 유지한다. 선수별 최근 팀 경기의 연속 득점·도움·공격포인트는 최신 경기부터 계산하며 0/미출전/불명확/누락/사후 수집된 상세가 있으면 멈춘다. 누락을 건너뛰거나 표본 전체를 역대 기록으로 확장하지 않는다. 2경기 이상 확인될 때만 연속 기록 문장을 제공한다.
- `record_notes`는 서버가 수치에서 만든 문장이다. LLM은 존재하는 player_id/team_id/focus/DB evidence_ids를 선택하고 선수별 reason을 한국어 3~5문장으로 작성한다. reason은 제공된 기록만 해석하며 전술·능력·심리·확정 선발·새 기록 수치를 추가하지 않는다. 화면의 선정 이유는 저장된 LLM reason을 그대로 표시하고 사실 기록은 서버가 만든 record_notes를 별도로 표시한다. 최초/최다/역대 신기록이나 리그 전체 순위는 자료 없이 주장하지 않는다. 근거가 없으면 내용을 만들지 않는다.
- fixture/detail/player/season stat의 관찰 시각과 킥오프 cutoff를 지킨다. 공개 GET은 저장본과 DB 선수 이름/사진만 읽는다. 검색+분석 기존 2회에 통합하며 세 번째 LLM 요청을 추가하지 않는다.

## 한글 이름·사진

선수 external_id → player → player_translation.name_ko를 사용한다. 사진은 Player.photo_url 및 확인한 API-Football injuries 응답의 player.photo 필드에서만 가져온다. URL을 ID로 임의 생성하지 않는다. 일반 조회는 저장된 URL을 반환하고 브라우저가 공식 CDN 이미지를 표시한다. 사진 URL이 없거나 이미지 오류가 나면 기본 인물 아이콘을 표시한다.

선수별 관전 카드와 부상 카드의 이름·사진은 조회 시 같은 DB resolver를 사용하므로 번역 수정이 다음 조회에 반영된다. AI 입력에도 번역된 player_name을 넣고 canonical_name/recognition_name은 식별용으로만 쓰도록 지시했다. 기존 자유 서술형 key_points 본문은 저장 텍스트이므로 이후 번역 수정에 따라 자동 문자열 치환하지 않는다. 새 ID 기반 선수 카드와 구분한다.

## 화면·호환

- 부상 카드 순서는 첫 행 홈1/원정1, 둘째 행 홈2/원정2다. 적격 선수가 적으면 해당 슬롯은 빈 상태이며 선수로 채우지 않는다. 전체 명단은 접힌 상태를 유지한다.
- 눈여겨볼 선수 섹션의 얼굴은 접기와 무관하게 보이고, 상세는 native details/summary로 기본 접힘·키보드 조작·다시 접기를 지원한다. 경기 전환 시 상세를 초기화한다. 이유/시즌·연속 기록/자료 시각을 보여준다.
- 새 필드는 기존 v1.1의 선택 필드다. 과거 저장본에 선수 관전 포인트가 없으면 그 섹션을 임의 생성하지 않는다. DB schema 변경·migration은 없다. FE Zod→공개 JSON Schema와 Vertex analysis schema를 같은 exporter에서 생성하고 drift 테스트한다.

## LLM 선정 이유 확정 — 사용자 후속 승인

초기 구현의 유형별 고정 설명을 사용자가 변경 요청해 선수별 `analysis.player_watchpoints.data[].reason`을 기존 analysis 모델 응답에 포함했다. 새 모델 응답에서는 필수이며 누락/빈 이유는 거절한다. 과거 v1.1 저장본 호환을 위해 공개 JSON의 reason은 선택 필드이고, 구버전은 ‘선정 근거’와 확인된 기록만 보여준다. 고정 문구를 LLM 선정 이유처럼 노출하지 않는다. 새 Vertex schema는 reason을 required로 생성하며 generation_version은 home-preview-1.1-prompt-6이다.

1557444 리버풀–브라이턴의 새 12시 슬롯 실행은 실제 API 4회·검색 1회·분석 1회로 성공했다. 플로리안 비르츠의 확인된 최근 팀 3경기 연속 공격포인트와 파스칼 그로스의 시즌 기록을 모델이 선택하고 각기 다른 reason을 작성했다. 실제 공개 JSON의 reason과 펼친 카드 문장이 같은지 데스크톱·390px L3에서 확인한다. 사진은 DB/API URL을 사용하고 모델 입력에서는 불필요한 사진 URL을 제외한다. 검색은 3개 질의였고 원문 검증 성공은 0건으로 정직하게 남겼다. 이 실행에서도 직접 생성 호출 수를 늘리지 않았다.

## 복합 선정 이유 — 최신 사용자 후속

사용자는 단순한 한 줄 이유가 아니라 확인된 기록을 복합적으로 해석하도록 요청했다. prompt-8은 시즌 득점/도움/출전 수·시간, 최근 경기의 확인된 기여, 연속 기록, 등록된 양팀 최근 폼 중 근거가 있는 최소 두 축을 연결해 3~5문장으로 설명한다. reason 한도는 1,000자다. 숫자는 제공된 범위에서 인용하고 분당/비율/최초/최다/순위 등을 임의 계산하지 않는다. 많은 무실점은 수비 안정 근거이고 득점 부족은 공격 지표라는 방향을 뒤집지 않는다. 전술/포지션/능력/확정 선발을 새 사실처럼 추가하지 않는다.

`recent_form`은 팀의 최근 경기 수, 출전이 확인된 경기 수, goals/assists/minutes 합계와 각각의 확인 표본 수를 별도로 보존한다. 득점 자료가 6경기만 확인되면 전체 10경기 득점이라고 설명하지 않도록 지시한다. NULL을 0으로 간주하지 않고 미출전/자료 미확인 경기를 임의로 포함하지 않는다. record_notes.recent_contribution은 이 표본 범위를 그대로 보여준다. 모바일에서 상세를 펼치면 눈여겨볼 선수 카드는 한 열로 넓어져 긴 이유와 기록을 읽을 수 있다. 부상 섹션의 2×2는 유지한다.

1557445 맨유–본머스는 새 슬롯 첫 응답이 ValidationError로 거절되어 이전본이 보존됐고, 허용된 동일 슬롯 1회 재시도에서 성공했다(실제 누적 모델 4회/API8회, 자동 추가 재시도 없음). 개발 중 이유를 대조하며 표본 범위와 수비 지표 방향을 교정했다. 사용자의 문장 수정 지시에 따른 **개발용 편집 검증 모델 호출 1회**를 별도로 수행했고, 검토된 실제 LLM 후보만 격리 로컬 DB의 새 불변 버전으로 저장했다. 이 추가 개발 호출은 snapshot.generation의 development_editorial_revision/development_model_requests/usage 및 parent_version_id에 명시했다. worker attempt·슬롯·원본 버전은 변경하지 않았으며 운영 생성 주기를 우회하거나 원격 DB에 반영하지 않았다. 운영 자동 생성은 여전히 검색+분석 2회이고 교정용 자동 세 번째 호출은 없다.

해당 로컬 예시는 브루노 페르난데스의 시즌 기록과 최근 **득점 확인 6경기 4골**, 마커스 태버니어의 확인된 최근 팀 2경기 연속 득점과 본머스의 최근 5경기 무실점 3회를 구분해 서술한다. 문장과 기록을 직접 대조했고 실제 L3는 공개 저장 문장과 카드 문장 일치, 표본·사진·모바일 펼침 폭을 확인한다. 최신 검증: BE100/FE27/E2E17/L3 4/build/lint PASS. 운영 DB 적용·배포·원격 반영·최종 독립 리뷰는 수행하지 않았다.
