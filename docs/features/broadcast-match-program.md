## 1. 개요

실제 경기 중계화면 또는 게임 중계 화면을 페이지 안에 크게 배치하고, 중계화면을 가리지 않는 별도 영역에만 축구 정보 그래픽을 배치하는 방송용 화면이다.

기존 `broadcast-match-overlay` 는 캐릭터 중심 크로마키 합성용 화면이고, 본 feature 는 영상 피드 자체가 화면의 중심인 프로그램 프레임이다.

## 2. 사용자

- 주 role: STREAMER
- 부가 role: ADMIN

## 3. 사용자 흐름

- 사용자는 매치 디테일 상단에서 `중계 화면` 버튼으로 별도 방송 페이지를 연다.
- 페이지는 좌측 큰 중계 영역과 우측 방송 보조 영역으로 2분할한다.
- 좌측 영역은 우측을 제외한 나머지 전체 폭을 사용한다.
- 좌측 상단/메인 영역에는 경기 영상 피드가 크게 표시된다.
- 좌측 하단의 남은 공간에는 주요 스탯, 이벤트, 보조정보를 큰 카드 단위로 하나씩 순환 표시한다.
- 우측 상단에는 외부 방송 채팅 UI 가 들어갈 공간을 둔다.
- 우측 하단에는 캐릭터가 들어갈 공간을 둔다.
- 골/카드/교체/VAR 같은 이벤트가 발생하면 좌측 하단 정보 큐브/스크롤 영역에서만 우선 노출한다.
- 하프타임/풀타임/전술 설명 상황에서도 중계화면 위를 덮지 않고, 하단 정보 영역 또는 별도 비영상 영역에서 처리한다.

## 4. 페이지 / URL 후보

- 페이지 이름: Broadcast Match Program
- URL 제안: `/broadcast-program.html?fixtureId=<external_id>&league=<league_slug>`
- 앱 라우트 브릿지: `/broadcast/program/fixtures/:externalId?league=<league_slug>`
- 방송용 페이지 여부: yes

## 5. 표시 데이터 (개념)

기본 경기 데이터:
- 홈/원정 팀명, 축약명, 로고/국기
- 스코어, 경기 시간, 추가시간, 경기 상태
- 리그/대회명, 라운드명

실시간 그래픽 데이터:
- 좌측 하단 순환 카드: 핵심 스탯, 골/카드/교체/VAR 이벤트, 선수 spotlight, 전술/보조정보
- 이벤트 목록: 골, 카드, 교체, VAR, 하프타임, 풀타임
- 핵심 스탯: 점유율, 전체슈팅, 유효슈팅, 코너킥, 오프사이드, 패스 성공률
- 선수 마커/선수 카드용 데이터: 등번호, 한글 축약명, 평점, 골 수, 카드, 교체 상태
- 포메이션/라인업: 양 팀 formation, starting XI, grid

영상 피드:
- MVP mock 에서는 실제 외부 중계 스트림을 붙이지 않고, placeholder video frame 또는 로컬 mock surface 로 표현한다.
- 실제 영상 소스 URL/캡처 방식은 별도 운영 결정이 필요하다.
- 저작권/중계권이 필요한 외부 경기 영상 임베드는 본 feature 의 구현 범위 밖이다.

## 6. 인터랙션

송출 화면 자체:
- 클릭 가능한 컨트롤을 노출하지 않는다.
- 중계화면 위에는 scorebug, lower-third, 이벤트 팝업, 분석 그래픽 등 어떤 웹 UI 도 올리지 않는다. 중계화면의 일부라도 웹 UI 가 가리면 약관 위반 리스크가 있으므로 금지한다.
- 좌측 하단 정보 영역은 cube flip 또는 위아래 vertical scrolling 으로 한 항목씩 순환한다.
- 모든 경기 정보 그래픽은 좌측 하단 22% 영역에만 배치한다.

디버그 / mock 전용:
- query param 으로 league theme 변경
- query param 으로 layout 후보 변경 가능
- mock 이벤트 루프 on/off 가능

## 7. 비기능 요구

- 기준 해상도: 1920x1080
- 레이아웃: flex/grid + `%`/`fr` 중심
- 비율 기준: 좌측 중계화면을 16:9 로 유지한다. 우측 폭을 기존 방송용 페이지 기준인 22% 로 두면 좌측 중계화면은 `78% width x 78% height` 가 되고, 좌측 하단 정보 영역과 우측 하단 캐릭터 영역은 남은 `22% height` 를 사용한다.
- 페이지 chrome: 일반 header/footer 없음
- 데이터 신선도: STREAMER 화면은 실시간 polling 허용. 기본 10초, 스탯/선수 세부는 캐시 TTL 차등 적용
- 영상 보호: 중계화면 영역 전체에 웹 UI overlay 를 배치하지 않는다. 하단 22% 정보 영역은 중계화면 밖의 별도 영역이며, 경기 영상과 겹치지 않는다.
- 가독성: 송출 캡처 기준. 작은 텍스트보다 숫자/팀 코드/아이콘 우선
- 반응형: 방송 기준은 1920x1080. 일반 모바일 대응은 MVP 제외

### 디자인 방향

본 화면 전체는 크로마키 화면이 아니지만, 우측 상단 채팅 영역과 우측 하단 캐릭터 영역은 OBS 합성을 위해 `#00B140` 크로마키 면으로 둔다. 좌측 중계화면과 좌측 하단 정보 영역은 월드컵 기준 테마를 기본으로 사용한다.

UI 원칙:
- 중계화면에는 스코어버그를 포함한 어떤 웹 UI 도 배치하지 않는다.
- 우측 상단은 채팅, 우측 하단은 캐릭터 공간으로 사용한다.
- 우측 채팅/캐릭터 영역은 웹 UI 를 그리지 않고 크로마키 색상만 표시한다.
- 주요 스탯/이벤트/보조정보는 좌측 하단 순환 카드에서 크게 보여준다.
- 전체 스탯/선수 카드/전술판은 좌측 하단 카드 또는 일시 그래픽으로 사용한다.
- 기본 시각 테마는 World Cup 2026 을 기준으로 둔다. 리그별 확장은 후속 후보에서 다룬다.

## 12. 미확정 / 메모

- 실제 영상은 웹 `<video>` 로 받을지, OBS/캡처 소스 위에 그래픽만 얹을지 결정 필요
- 이 화면은 기존 `/api/v1/broadcast/fixtures/{external_id}/overlay` payload 를 우선 재사용 가능하다
- 추가 endpoint 는 영상 소스/방송 제어 요구가 확정된 뒤 판단한다
- 우측 채팅/캐릭터 크로마키 영역은 방송 합성 대상이므로 내부 placeholder UI 를 넣지 않는다
