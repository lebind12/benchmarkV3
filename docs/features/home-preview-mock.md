# 메인 추천 경기·AI 프리뷰 평가 목업

2026-10-25 사용자 요청. 추천 정책 정본은 `plan.md` §5.2.1. 개발 전용 `/home/mock`, 실제 `/` 교체 전 사용자 평가 단계다.

## 화면과 구현 범위

- 기존 헤더와 Pretendard, 흰색/짙은 본문/회색 보조/파랑 조작 강조, 기존 dark 토큰을 사용한다. 시각 중심은 큰 양 팀 공식 엠블럼 대결 구도다. 주변 근거는 조용한 읽기 영역으로 둔다.
- 로고에만 550ms/22px 좌우 진입. 경기 전환 버튼·목록·좌우 키·터치 swipe 지원. 자동 넘김·polling·생성 API 호출은 없다. 감소 모션에서는 애니메이션을 제거한다.
- DB 저장 상태 기준 진행 중을 우선하고 예정은 확정한 대회 순서·킥오프 순서로 표시한다. 종료는 오늘 결과에 분리한다. 중요 경기 4개 제한 없이 전체 선택 가능, 단일 경기 전환 비활성, 추천 없음/다음 예정 날짜 안내를 제공한다.
- 동일 fixture의 헤더/팀/프리뷰/부상/최근 기록/예측/외부 전망/배당이 함께 전환된다. 기존 최근 기록·순위·스탯 대시보드는 경기 탭 등을 활용한다.
- `준비 완료 / 일부 자료 부족 / 준비 중 / 불러오기 실패 / 이전 유효본`과 로고 누락, 최근 경기 표본 부족을 평가할 수 있다. 다시 확인은 로컬 성공 상태로만 전환하며 실제 요청·재생성을 하지 않는다.
- API-Sports의 기존 팀 엠블럼 URL만 사용한다. 일정·기록·부상·AI/외부 분석·배당은 가상 샘플이다. 외부 출처를 실제 매체로 위장하거나 가짜 원문 링크를 만들지 않는다. 샘플 fixture를 실제 상세 경기에 연결하지 않는다.

## FE-first 응답 요구 초안

아래는 평가 후 endpoint-request로 구체화할 후보이며 BE 계약/구현 확정이 아니다.

| 조회 후보 | 필요한 응답 |
|---|---|
| `GET /api/v1/home/recommendations?date=YYYY-MM-DD` | requested_date, display_date, timezone, fallback_reason, 정책 버전, 자료 기준 시각, 우선순위·추천 이유별 중복 없는 fixture 목록, 팀/대회/라운드/킥오프/저장 상태, preview 상태, 오늘 결과. 외부 ID 사용 |
| `GET /api/v1/home/fixtures/{external_id}/prematch` | fixture_id, 영역별 상태/기준 시각/누락 사유, summary, key_points, injuries(확정/불확실·출처), recent_form(킥오프 이전·실제 표본 수), ai_prediction, external_predictions, odds(북메이커·90분 decimal 시장·수집 시각), sources(원문 URL·발표/확인 시각), generated_at, 이전 유효본 여부 |

메인/화살표 요청은 저장본 조회만 수행한다. 프리뷰 조회 재시도와 생성 재실행을 구분한다. 새로운 DB/워커·실제 상세 연결은 사용자 평가 이후 BE 명세 단계에서 진행한다.

## 검증과 제약

검증 결과는 `docs/features/home-preview-mock.verification.md`를 따른다. 작업 디렉터리에 기존 관리 구현 변경이 있어 브랜치 전환·커밋·하네스 상태 전환 없이 현재 checkout에서 독립 파일과 라우트 1개를 추가했다. 기존 관리 하네스의 완료/리뷰 상태로 보고하지 않는다. 이번 목업은 root 자체 검증이며 독립 리뷰 승인을 받았다는 의미가 아니다.

## 2026-10-25 화면 평가 반영

- 메인 제목을 `오늘의 매치`로 변경.
- 프리뷰에 반투명 유리 표면, backdrop blur, 팀 색상의 은은한 배경을 적용. 스크롤 진입에 따라 각 영역의 흐림/투명도/20px 이동이 점진적으로 걷힌다.
- 한 번 드러난 내용은 다시 흐려지지 않으며, 키보드 포커스와 감소 모션에서는 바로 선명하게 표시한다. 실제 페이지 scroll container 기준이며 resize/경기 전환/상태 변경도 반영한다.

- 추가 평가 반영: 큰 제목을 `경기 전 프리뷰`로 단순화하고 반복 면책 문장을 제거했다. 상단 목업 고지, 자료 누락·이전본 상태, 출처·자료 시각 및 AI 예측 구분은 유지한다.

## 누락 자료 우선 표시·동적 안내 — 사용자 평가 반영

- 프리뷰 제목 아래 `자료 확인 현황`에서 미제공 항목을 먼저, 일부 제공 항목을 다음에 표시한다. 항목 클릭 시 해당 영역으로 이동하고 키보드 포커스도 전달한다.
- 부상·출전 정보/홈 최근 5경기/원정 최근 5경기/AI 예측/외부 전망/배당의 제공 상태를 독립적으로 처리한다. 최근 경기는 일부 제공과 미제공을 구분한다. 모든 자료가 있으면 누락 안내를 숨긴다.
- 문구는 누락 조합·표본 수에 맞춰 자동 구성한다. 평가 도구에서 선택 경기의 상태와 안내 문구를 직접 수정·초기화할 수 있다. 문구만 바꿔도 구조화된 누락 목록은 유지한다.
- 목업 편집은 fixture별 메모리에만 보존하며 서버/DB에 저장하지 않는다. 새로고침 시 샘플 기본값으로 돌아간다. 경기 전환 시 다른 fixture의 변경을 섞지 않는다.
- 없는 자료의 샘플 본문과 출처는 함께 숨긴다. 부상 정보 미수집을 결장자 0명으로 표현하지 않는다.
- 후속 API 요구: 영역별 `status`, `reason`, `as_of`, 최근 경기의 실제 `sample_count`/`expected_count`, 선택적 표시 문구. 응답의 실제 자료·상태에서 누락을 판단하며 단일 `partial` 플래그만으로 외부 전망·배당 누락을 단정하지 않는다. 실제 API 구현은 후속 범위다.

## 구조화 JSON 후속 반영

본문을 `frontend/src/mocks/home-preview/previews.json`과 strict Zod 계약에서 렌더링하도록 전환했다. 평가 도구의 `프리뷰 JSON`에서 편집·적용할 수 있다. DB/웹/AI 분리와 생성 스키마·후속 BE 계약은 `docs/features/home-preview-json.md`가 정본이다.
