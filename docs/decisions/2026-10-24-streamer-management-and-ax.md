# 2026-10-24 — 스트리머 공통 관리 및 AX 범위 결정

근거: 사용자의 2026-10-24 요청. 상태: 정책 변경 확정, 기능 구현 전.

## 확정된 변경

1. 수집 대상 설정·수집 실행·실행 추적·번역 검수는 인증된 `STREAMER`와 `ADMIN`에게 제공한다. 서버가 DB 사용자와 역할을 검증한다. 수집 설정·번역 변경은 사용자 개인 설정이 아니라 전체 서비스 공통이다.
2. 리그·팀·선수·감독 번역의 목록·검색·수정·검수 상태·수정자/시각·변경 전후 이력·동시 수정 충돌 처리를 이번 범위에 포함한다. 기존의 “번역 검수 post-MVP” 제외 결정을 대체한다. 사람 수정은 이후 수집·자동번역·import에서 보호한다.
3. 방송용 페이지의 `STREAMER` 사용 정책을 유지하며 현재 코드의 ADMIN 제한·mock 권한 우회를 공통 서버 인증으로 정합화한다. 역할 변경·사용자 관리를 STREAMER에게 추가 허용하는 결정은 아니다.
4. 일반 페이지는 DB 전용·6시간 갱신, 최신 2시즌, 원본/번역 분리, API-Football 전체 한도·재시도·중복 실행 방지, 환경별 Redis prefix 정책을 유지한다. 운영 배포·재시작·배포 환경변수 변경은 사용자의 명시적 배포 요청 없이는 수행하지 않는다.
5. 후속 사용자 답변: 홈에서 종료 경기는 예정 경기 추천과 분리해 `오늘 결과`에 표시한다. 오늘 종료 경기만 남았을 때의 추천 날짜 이동까지 확정한 것은 아니다.
6. 후속 사용자 답변: 홈 추천은 기준별 후보 묶음을 먼저 화면으로 만들지 않고 단일 순위·동률 기준을 정한 뒤 화면을 구성한다. 구체 순위안은 아직 채택하지 않았다.
7. 프론트 화면·흐름·mock 응답 요구 → endpoint-request → BE 명세·구현 → FE 연동 순서를 유지한다. 이번 단계는 코드 대조와 기획 제시이며 전체 구현 시작을 의미하지 않는다.
8. 후속 사용자 방향: 홈 큐레이션과 일반·관련 페이지는 디자인 개선을 중심으로 한다. 현재 구현/기존 미연결/미구현 기능을 먼저 구분하고 기존 기능을 활용한다. 관리 완성·자연어 검색 목표를 취소하거나 추가 후보를 필수 범위로 편입하는 결정은 아니다.
9. 최신 홈 방향(앞선 일반적인 인터랙션 해석을 구체화): 메인 진입 시 오늘 추천 경기와 AI 프리뷰를 확인한다. 양 팀 로고가 페이드인하며 부드럽게 등장하고 좌우 화살표로 우선순위 경기들을 넘긴다. 기존 일정 탐색은 경기 탭이 제공하므로 메인에서 대시보드를 반복하지 않는다. 메인 안에서 주요 부상·관전 포인트·AI 예측·주요 사이트 전망·양 팀 배당·최근 5경기 흐름을 확인한다. 외부 전망/배당은 확인한 출처·시각과 함께 저장하고 AI 사실 창작과 구분한다. 일반 페이지 DB/6시간 정책은 유지한다.
10. 빅6 EPL 및 UCL 8강·4강·결승의 추천/프리뷰를 핵심 검증 범위로 둔다. 빅6가 없어도 UCL 4강·결승과 UEL 결승은 중요 경기로 포함한다. 중요 경기 포함이 기존 모든 순위를 자동으로 뒤집는 결정은 아니며 전체 세부 순서는 미정이다. 앞선 A/B 검토안은 최신 예외를 반영하지 못해 채택하지 않았다.
11. 최신 개발 우선순위: 관리 기능 완성을 먼저 진행한다. 공통 인증·대상·실행/취소/복구/이력·번역 검수·필요 운영 정합을 MGMT 단계로 계획하고 기능별 FE-first 순서를 지킨다. 메인 추천/프리뷰와 자연어 검색은 후속으로 유지한다. 이번 요청의 산출물은 개발계획이며 기능 구현·하네스 실행·운영 적용/배포 완료를 의미하지 않는다.
12. 관리 하위 탭은 `수집 대상 / 수집 실행 / 실행 이력 / 번역 검수` 네 개로 구체화한다. 최신 사용자 지시로 네 탭 전체의 로컬 평가용 목업을 먼저 구현하고 사용자 평가 이후 BE를 진행한다. 샘플 MSW/전용 저장만 사용하며 실제 서버 인증·작업 실행·DB 이력 완성으로 보고하지 않는다. 평가 전 BE lifecycle·원격 push/merge·배포는 시작하지 않는다.

## 유지되는 미정·제외 사항

- 정기 수집 주기 변경 권한, 추천의 미결정 대회 순서·동률·오늘 자격/예정 경기 없음 시 날짜 이동, 수동 고정/제외는 확정하지 않았다.
- 뉴스 번역 편집·AI 의심 표기 추천·실패 원인 AI 설명·방송 소재·경기 후 리뷰는 필수 범위에 포함하지 않았다.
- 데이터 삭제 권한과 수집 대상 제외는 별개다. 이번 결정이 임의 운영 데이터 삭제를 허용하지 않는다.

상세 현황·화면/API 제안: [plan.md](../../plan.md). 작업 정본: [Plans.md](../../Plans.md). 기존 문서에서 이 결정과 충돌하는 ADMIN 전용 관리/방송, 번역 검수 제외 문구는 이 결정으로 대체한다. 코드 구현 상태는 문구 변경과 별개로 검증한다.

## 2026-10-25 목업 피드백 결정

- 검수 상태를 별도로 관리하지 않고 번역/미번역만 표시한다. 한국어 이름 기준이며 짧은 이름은 선택 사항이다. 수정자·시각·이전/이후·보호·충돌 처리는 유지한다.
- 카탈로그는 기존 `/admin`의 DB 조회/외부 최신화 분리와 시즌 선택 방식으로 개선한다.
- 실행 이력 실패 로그와 원인별 통계를 제공한다. 한국어 표시는 구조화 이벤트 코드 대응을 기본으로 하고, 이전 로그는 인식 가능한 문구만 제한적으로 대응하며 원문과 미분류를 유지한다. 실제 BE 이벤트/집계 저장은 사용자 평가 후 구현한다.

## 2026-10-25 메인 목업 착수 결정

- 사용자 승인으로 메인 FE 목업을 현재 작업으로 진행한다. 관리 기능의 기존 변경은 보존한다.
- 추천 순서: 빅6 EPL → 나머지 EPL → 빅6 UCL 8강·4강·결승 → 비빅6 UCL 결승 → 비빅6 UCL 4강 → 비빅6 UEL 결승 → 빅6 UEL·기타 대회 → 비빅6 UCL 8강. 동일 그룹 킥오프 오름차순, 완전 동률 fixture ID 오름차순.
- 진행 중을 예정 경기보다 앞에 두고 각 상태 안에서 같은 추천 순서를 적용한다. 종료는 오늘 결과로 분리한다. 오늘 추천 자격의 진행 중/예정 경기가 없으면 가장 가까운 추천 예정 날짜로 이동한다.
- 상태는 DB 저장 기준이며 실제 진행과 차이가 있을 수 있다. 6시간 갱신·DB 전용·polling 금지·라이브 점수/카운트다운 금지를 유지한다. 사전 프리뷰의 작성 시각과 자료 시각을 표시한다.
- 개발 전용 `/home/mock`에서 가상 샘플로 평가한다. 기존 `/` 교체·BE 구현·운영 데이터 변경·배포는 이번 목업에 포함하지 않는다. 앞선 미정 순서/동률/날짜 이동 및 관리만 우선이라는 실행 기록은 이번 요청 범위에서 대체한다. 수동 고정/제외는 미정이다.

## 2026-10-25 실제 관리 화면·BE 연결 승인 및 구현

사용자가 평가 목업의 실제 반영과 백엔드 구현/연결을 명시적으로 요청했다. 해당 네 탭에 필요한 API 계약을 작성한 뒤 실제 `/admin`, JWT·서버 역할 검사, 대상/카탈로그, 영속 실행·취소/복구/이력, 번역 CAS/감사/보호를 구현했다. 운영 적용과 구분해 별도 로컬 DB에서 검증하며 다른 워커 자동 등록·스케줄 변경 권한·배포까지 승인된 것으로 해석하지 않는다. 최신 구현과 검증은 `docs/features/streamer-management-api.md`, `docs/features/streamer-management.verification.md`를 따른다.

### 기존 DB 연결 제보 후 반영

사용자의 “DB가 엇갈려 로그인되지 않는다”는 제보를 확인했다. 기존 5173/8000은 원래 Supabase를 유지했고 5187/8016만 격리 테스트 DB였다. 기존 화면의 Origin403과 로컬 JWT/HTTP cookie 누락을 수정하고 개발 요청을 동일 주소 proxy로 통일했다. 검증된 0017을 기존 Supabase에 적용했고 head를 확인했다. 계정/역할/경기 자료와 DB URL은 변경하지 않았으며 배포·운영 서비스 재시작·배포 환경변수 변경은 하지 않았다.
