# 2026-10-28 운영자 주도 하네스 결정

## 결정

현재 루트 대화 세션이 사용자와 계획하고 자식 에이전트를 조정하는 운영자다. 운영자 모델은 고정하지 않는다. 개발자는 구현 후 병합을 요청하며, 독립 테스트 담당자는 운영자가 정한 의도를 기준으로 실제 기능을 시험한다. 운영자가 원본·diff·테스트 증거를 직접 검토하고 병합을 유일하게 결정한다. 변경 요청 후에는 수정과 재시험을 반복한다.

계획에는 공식 근거와 호환성·비용·복잡도를 비교하는 기술 조사 역할을 둔다. 사용자·서비스 조사, 사용자 흐름·요구사항 검증, 결과·운영 검토는 맥락에 따라 추가한다. 계획 확정과 주요 이정표에서 서비스 포트폴리오 제작에 필요한 결정과 증거를 모은다. 결과물은 서비스 전체를 설명하는 모션 그래픽이며 수치와 성과를 창작하지 않는다. Notion은 목적지와 범위가 승인된 경우에만 선택적 증거 저장소다.

최초 설계에서 새 작업은 `work-flow` 상태를 사용했다. 같은 날 [진행 방식 구분 후속 결정](2026-10-28-development-modes.md)으로 FULL에 적용하고 QUICK은 간단한 기록으로 진행하도록 변경했다. 기존 FE/BE 상태는 과거 기록으로 보존하고 기존 제품 개발 순서와 도메인 정책은 유지한다. 상태 기록은 실제 실행이나 권한을 대체하지 않는다. 상세 절차와 모델 기본값은 [운영 명세](../spec/agentic-workflow.md)를 따른다.

## 범위 및 상태

이 결정은 운영 정책을 기술한다. 특정 서비스 기능의 구현, 테스트, 배포 또는 측정 완료를 주장하지 않는다. 기존 `AGENTS.md`의 worktree 및 배포 제한을 유지한다.
