# 뉴스 문맥 연결: 결과 원문 수정 금지와 검증 도구 테스트 범위

2026-10-29 사용자 후속 결정. 이전 기획·테스트의 상충하는 원문 수정 흐름보다 이 결정을 우선한다.

- 입력 화면에서 붙여넣은 글을 준비한다. 분석 결과 화면의 원문과 출처는 읽기 전용이며, 원문을 수정하는 입력란이나 `입력 수정` 동작을 제공하지 않는다. 연결 대상·조회 조건·공통 판단의 선택과 수정은 유지한다.
- 결과 화면에서 확정한 연결 이후 원문을 수정하여 무효화하는 흐름은 지원 기능이 아니므로 해당 테스트를 추가하지 않는다. 대신 실제 결과 화면에 원문 수정 입력란·버튼이 없고 원문을 그대로 읽고 호버할 수 있는지 확인한다. 서버의 문서/버전 검증과 이전 작업 응답 격리는 유지한다.
- 증거 검사기 자체는 정상 기준 증거의 수용과 대표 결함의 거부를 확인하는 짧은 테스트로 검증한다. 별도 장기 검증 단계나 반복적인 검증의 검증 절차를 추가하지 않는다. 합성 기준 증거는 실제 LLM 품질·통합 E2E 통과 증거로 사용하지 않는다.

이 기록은 변경 결정이며 전체 E2E 또는 독립 구현 검토 완료를 의미하지 않는다. 이전 동결 계약·검토 결과는 보존하고, 후속 계약과 테스트에서는 이 변경을 명시적으로 반영한다.
