# 프리뷰 폐기 후 추천 경기 조회 복구

사용자 요청:

> 현재 운영페이지에 추천 경기 목록을 가져올 수 없는 문제가 있음. 이전에 제거한 프리뷰 기능때문인거 같은데 문제 확인 후 복구좀.

확인 사실:

- 운영 `GET /api/v1/home/recommendations`가 `503 home_preview_storage_unavailable`을 반환한다.
- 기존 추천 서비스는 경기마다 프리뷰 게시 정보를 읽었다. 프리뷰 폐기 후 실제 DB에는 `fixture`가 남아 있고 `home_preview_publication`과 `home_preview_version`은 없다.
- 삭제 작업의 로컬 코드에는 추천 API 라우트가 없고 프론트 추천 함수는 빈 목록을 반환했다.

복구 범위:

- 기존 추천 API 경로와 응답 계약, KST 날짜, 추천 순위 및 가까운 예정일 대체 동작을 유지한다.
- 경기·리그·수집 대상·번역 DB만 읽는 독립 서비스로 추천 목록을 제공한다. 프리뷰 게시 정보는 조회하지 않으며 응답의 프리뷰 상태는 `unavailable`로 표시한다.
- 프론트에서 실제 추천 API를 다시 조회한다. 홈의 프리뷰 영역은 미제공 상태를 안내하고 삭제된 조회/생성 API를 요청하지 않는다.
- [프리뷰 폐기 결정](2026-11-08-remove-home-preview.md)은 유지한다. 프리뷰 백엔드·생성본·모델·워커·테이블·외부 AI 호출은 복원하지 않는다.
- 이번 복구는 관련 자동 테스트와 실제 저장된 경기 데이터로 검증한다. 이전 삭제 작업에 한정됐던 테스트·빌드 생략과 구분한다.
- 운영 배포는 `AGENTS.md`의 명시적 배포 요청 원칙을 따른다. 로컬 검증과 운영 복구 완료를 구분한다.

검증 결과와 인계는 `out/home-recommendations-repair/result.md`에 기록한다.

## 후속 사용자 지시: 문구 간소화와 운영 배포

> 프리뷰는 제공예정 문구만 남겨두셈. 그담에 프론트 백엔드 배포 ㄱㄱ

- 홈 프리뷰 영역은 `프리뷰 제공 예정` 한 문장만 표시한다. 추가 설명·아이콘·프리뷰 내 버튼은 표시하지 않는다.
- 수정된 프론트와 백엔드의 운영 배포를 명시적으로 승인했다. 기존 Vercel `woolees-projects/benchmark-v3`, Koyeb `benchmark-v3/api`를 대상으로 한다.
- 검증한 현재 소스를 별도 배포 묶음으로 고정하며 원본 Git HEAD·index와 다른 작업 변경은 보존한다. 로컬 환경 파일·인증 파일은 배포 묶음에 포함하지 않는다.
- DB 마이그레이션이나 프리뷰 생성 복구는 배포 범위에 추가하지 않는다.
