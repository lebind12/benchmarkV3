# 2026-10-29 — AX 서비스 완성과 하네스 보완

## 사용자 지시
하네스 감사의 보완 순서대로 현행 기획 정리부터 진행한다. 완성 목표는 완성된 서비스의 머지 및 배포다. 추가로 프롬프트 인젝션을 고려한다.

## 적용
- 현행 제품 요구는 `docs/features/ax-agentic-search.md`, 실행 상태는 `Plans.md`, 실행 순서와 출시 경계는 `docs/ax/natural-language-search/plan.md`로 연결한다. 에이전트 검색과 진행 표시를 현행 feature로 등록하고 과거 v1/목업은 회귀·역사 근거로 보존한다.
- 기존 8개 선수 시즌 지표·다중 선수·두 시즌 비교·자연어 확인·근거/누락 표시를 최초 출시 범위로 정리한다. 기존 결정에서 보류한 팀/경기 통계·추가 조건은 이번 정리로 구현 완료/지원 확정 처리하지 않는다.
- 과거 로컬 산출물 완료와 하네스 승인·운영 인수를 분리한다. 과거 상태/승인/머지 이력을 소급 생성하지 않고 현재 시점에서 기획·명세·구현을 재검토한다.
- 직접/간접 프롬프트 인젝션은 보안 인수의 필수 차단 조건이다. 사용자/대화/DB 유래 입력을 데이터로 취급하며 모델 제안과 서버 실행 권한을 분리한다. 공격과 정상 입력을 모두 독립 정답·부작용 검사로 평가한다.
- 기술 검증과 서비스 통합·기존 공통 인증/전용 읽기 경로·운영 갱신·독립 holdout·기준선·리뷰·머지·승인된 배포/사후 smoke를 별도 과제로 관리한다.
- 배포가 최종 목표라는 지시를 보존한다. AGENTS.md의 명시적인 “배포해” 요청 조건은 유지한다. 준비·읽기 조사·코드/문서/격리 테스트는 진행하고 서비스 배포·환경변수 변경·재시작은 해당 요청 전 실행하지 않는다.
- AX worktree/브랜치를 유지한다. 다른 세션의 HEAD/인덱스/작업 파일은 변경하지 않고 최종 머지는 PR/커밋 기반으로 조정한다. 자동 배포를 유발하는 머지는 배포 승인 단계에 포함한다.
