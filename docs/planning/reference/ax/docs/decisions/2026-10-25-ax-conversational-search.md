# 대화형 검색과 승인 목업 유지

사용자가 기존 목업과 실제 화면의 차이를 지적한 뒤, 결과를 바탕으로 '상위 두 선수 비교' 같은 후속 질문을 요청했다. 이어 검색 시나리오를 더 넓혀 테스트하도록 지시했다.

첫 화면/검색창/글래스/모션은 승인 목업을 기준으로 되돌리고 대화 스레드와 후속 입력을 추가한다. 명확한 질문은 별도 실행 확인 없이 조회까지 진행하고 필요한 모호함만 확인한다. 로그인은 기존 공통 authority에 위임하며 입력을 지우지 않는다.

모델이 대화를 기억한다고 가정하지 않고 서버가 검증된 조건·실제 결과·참조를 보관한다. 변경하지 않은 조건의 상속과 실제 표시 행/순위 참조를 검증한다. 자유 문장/선택 답변·오류·취소·유실 재시도·새 대화를 테스트한다. 결과 설명/비교 차이는 DB 수치로 서버에서 생성한다.

기존 지정 Vertex 모델·읽기 전용 SQL/2시즌·DB-only·6시간·로그인 정책을 유지한다. 계정별 영속 대화·새 캐시/워커·지원 지표 확장·운영 DB 변경/배포는 포함하지 않는다. 기존 AX checkout만 수정하며 다른 세션의 HEAD/인덱스를 변경하지 않는다. 검증 범위와 보류는 [대화형 구현](../ax/natural-language-search/conversational-search.md)을 따른다.
