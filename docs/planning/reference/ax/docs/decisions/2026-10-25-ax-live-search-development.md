# AX 실제 검색 개발 경로와 운영 적용 분리

사용자의 "나머지 순서까지 계속 진행" 지시에 따라, 기존 AX checkout에서 실제 모델·실데이터·인증·SQL·FE 연결과 로컬 통합 평가를 이어간다. 새로운 worktree나 브랜치 전환은 하지 않는다. 다른 관리/메인 세션의 작업 파일·HEAD·인덱스는 변경하지 않는다.

공통 인증이 원본 서버에 구현되어 있으므로 해당 HTTP authority의 JWT/활성 사용자 검증을 재사용한다. 다른 세션의 미커밋 인증 구현/환경 파일을 AX checkout으로 복사하지 않는다. 원본 DB 계정은 검색에 부적합한 권한을 가지고 있어 READ ONLY 축구 데이터 export만 사용하며, 온라인 실행은 전용 local PostgreSQL SELECT-only view role로 제한한다. 기존 DB 기반 실제 데이터의 로컬 복제본이라는 점을 화면과 문서에서 명시한다.

최초 지원은 선수 시즌8지표의 목록/순위/최대2명 비교다. 정확 이름 검색/사용자 확인, NULL/합계비율/시즌 정책과 실행 제한을 적용한다. 선택 기술·로그인 필수·지정 모델·2시즌/6시간·DB-only 정책은 유지한다. 런타임 사전은 검증된8개만 사용하며 나머지 초안 전체를 활성화하지 않는다. 실제 모델 지연에 따라 개발 예산60초/회·180초/해석을 적용했으며 전체15초 후보 SLO 충족으로 보지 않는다.

[구현·한계](../ax/natural-language-search/live-search.md), 사용 안내 (원문 참조 경로: `../ax/natural-language-search/evaluation/manual-live-search.md`; 이 기획 묶음에 포함되지 않음), [FE 요구](../features/ax-search-live.md), [API 명세](../spec/endpoints/ax-search-live.md)를 따른다. 원격 role/migration·독립 품질 인수·공통 앱 등록·배포·머지는 별도 상태로 남기며 이번 작업으로 수행/완료했다고 간주하지 않는다.
