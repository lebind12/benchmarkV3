# 대화형 자연어 검색 v1

2026-10-25 사용자 요구: 검색 결과를 바탕으로 후속 질문이 이어져야 한다. 예: EPL 득점 순위 → 상위 두 선수 비교 → 도움 기준 비교 → 직전 시즌. 기존 목업의 UI/UX를 기준으로 실제 연동한다.

화면은 목업의 중앙 소개/880px 폭/글래스 배경·64px 한 줄 검색창·돋보기/원형 전송·예시 카드·검색 후26px 제목·파형/스켈레톤/문구6개 순환·결과 행 등장 효과를 재사용한다. 첫 질문 후 사용자 질문과 assistant 답변/결과/재질문을 시간순으로 쌓고, 하단 입력으로 후속 질문을 보낸다. 명확한 질문은 조회 결과까지 한 번에 반환한다. 필요한 모호함만 되묻는다. 로그인 전에도 입력을 유지하고 제출 시 로그인 dialog를 연다. 로그인 성공 후 사용자가 요청했던 검색을 이어간다. 새 대화는 기존 문맥과 UI를 초기화한다.

결과는 실제 수치 표와 서버가 생성하는 짧은 답변, 적용 대회/시즌/지표/필터·시각/부분 수집 상태를 포함한다. 선수 비교는 선수별 행을 같은 지표의 열로 보여주고 득점·도움·출전 횟수·시간을 함께 표시한다. 없는 값은 자료 없음이다. 통계 서술은 DB 수치에 근거한 서버 포맷으로 만들고 LLM 임의 설명을 사실로 노출하지 않는다.

대화는 로그인 세션/자료 버전에 귀속하며30분·최대12개 교환·최대64대화로 제한한다. 모델에는 최대12개 교환의 조건/질문/결과 ref·표시 행 수와 최근4개 결과의 앞10명을 전달한다. 전체 결과는 서버에 남겨 이전 결과의 위치 참조를 검증한다. 결과 위치 참조는 실제 표시한 결과에서 서버가 결정한다. 다른 대화/다른 사용자/위조·만료/자료 교체·중복/지나간 parent ref는 차단한다. '상위 두'는 표시 순서의 앞2명, 명시 순위값은 공동순위/없는순위 여부를 검증한다. 결과에 없는 선수를 추정하지 않는다.

기존 단발 해석/조회 API는 호환 유지하며 실제 대화 화면은 아래 endpoint를 사용한다. 공통 인증·Gemini 모델·DB-only/2시즌·SQL 안전 게이트는 유지한다. 대화 영속 저장·새 Redis 키·운영 배포·팀/경기 통계·지원 지표 확장은 이번 변경에 포함하지 않는다.
