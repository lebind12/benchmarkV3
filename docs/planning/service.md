# 공통 축구 서비스·홈·방송

현재 상태: **기획 보존 / 구현 삭제**. 아래 정책은 재개발 때 확인할 기존 사용자 결정이며 현재 실행 환경의 사양을 의미하지 않는다.

## 서비스와 데이터 정책

- 일반 이용자에게 경기 일정·결과, 경기 상세, 순위, 팀, 선수, 기록, 뉴스 정보를 제공한다. 별도 방송 화면은 방송 소프트웨어에서 캡처·크로마키 합성하는 용도다.
- 초기 대회는 EPL(39), UCL(2), UEL(3), 카라바오컵(48), FA컵(45). STREAMER/ADMIN이 서비스 공통 수집 대회를 추가·제외하며 활성 리그와 수집 대상의 상태를 일치시킨다.
- 보관 범위는 대회별 현재 시즌과 실제 직전 시즌이다. 컵 대회는 시즌 전체를 대상으로 하고 미정 라운드는 빈 슬롯으로 구분한다. 외부 ID로 중복 없이 갱신한다.
- 일반 페이지는 DB 저장본만 읽고 6시간 갱신을 전제로 한다. 클라이언트 polling, 실시간 점수·카운트다운을 제공하지 않는다. 라이브 조회는 방송용 endpoint와 워커로 한정한다.
- 데이터 출처 API-Football, DB Supabase/Postgres, 백엔드 FastAPI·SQLAlchemy, 프론트 Vue·Vite라는 기존 기술 방향을 보존한다. 현재 설치된 코드·의존성은 없다.

## 인증과 역할

- 공개 일반 페이지와 로그인 기능을 구분한다. 자연어 검색은 활성 USER/STREAMER/ADMIN의 로그인이 필수다.
- 수집 관리·번역 수정은 STREAMER/ADMIN의 서버 권한 검사를 거친다. 방송은 기존 STREAMER 전용 정책을 따른다.
- 짧은 JWT access와 refresh rotation/blacklist를 사용한다는 설계를 보존한다. Upstash의 MVP 용도는 refresh 세션 관리이며 응답 캐시 확대는 후속 검토다. 방송 캐시 요구와 MVP 적용 범위는 재개 시 계약에서 정합화한다.
- Redis를 사용하는 모든 키는 local/prod 환경 prefix로 분리한다.

## 수집과 번역

| 작업 | 주기·책임 |
|---|---|
| daily-sync | KST 00/06/12/18, 활성 대회·최신 2시즌의 경기/상세/팀/선수/감독/순위/이적/부상 |
| translation-filler | 1분, 새 entity의 미번역 이름을 음역; 큐가 비면 종료 |
| news-fetcher | 1시간, EPL 관련 RSS 제목·요약·URL 저장 |
| news-translator | 1분, 미번역 뉴스 제목·요약 번역; 큐가 비면 종료 |

외부 요청 한도는 기존 Ultra 기준 450회/분, semaphore 상한 6, 한 사이클의 지수 백오프 재시도 최대 3회다. 단일 스케줄러·외부 ID upsert·부분 적재 후 재시작을 전제로 한다.

리그·팀·선수·감독의 원문과 한국어 번역은 분리한다. 수집은 번역 행만 보장하고 기존 한국어를 덮어쓰지 않는다. 자동 음역은 기존 `gpt-3.5-turbo`와 시드 기반 few-shot 방향을 보존한다. 사람이 수정한 값은 수집·자동 번역·import에서 보호한다. 일반 API는 한국어 미등록 시 원문 fallback을 제공한다. 뉴스 문맥의 한국어 카드 표시 규칙은 해당 기획의 별도 요구를 따른다.

## 홈과 프리뷰

최근 홈 기획은 오늘 추천 경기와 프리뷰 중심이다. 추천 자격·우선순위·KST 날짜 및 가까운 예정일 대체 규칙을 유지한다는 기존 결정을 보존한다. 카라바오컵·FA컵은 준결승/결승에서만 기존 추천 자격을 평가한다.

2026-11-08 기존 프리뷰 백엔드·생성본을 폐기했고, 이후 추천 경기 조회를 독립적으로 복구하고 프리뷰 영역에는 `프리뷰 제공 예정` 문구를 사용하기로 했다. **2026-11-09에는 남아 있던 홈·관리 UI 소스와 추천 구현도 삭제했다.** UI 보존 예외는 끝났으며 새 프리뷰 구현은 미착수다. 과거 생성 시점·외부 전망·배당·선수 관전 포인트 등은 참고 요구로 남기고 재개 승인이나 현재 지원으로 간주하지 않는다.

## 방송 화면

크로마키 오버레이와 경기 중계 화면 중심의 프로그램 프레임을 구분한다. 크로마키 색은 OBS 기본 녹색 `#00B140`이며 UI 내부에 유사 색상을 쓰지 않는다. 크로마키가 카드 안으로 비치는 투명도는 금지하고 불투명한 에셋 위의 내부 하이라이트는 허용한다. 영상 위 상시 UI를 피하고 별도 정보 영역·채팅/캐릭터 합성 영역을 설계한다. 실제 영상 소스 연결 방식은 기존 미확정 항목이다.
