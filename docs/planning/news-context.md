# 기사·커뮤니티 문맥 연결

현재 상태: **v6 기획 보존 / 구현 삭제**. v6의 설계 제안과 사용자 확정 사항을 구분하며, 독립 기획 검토를 서비스 검증 완료로 간주하지 않는다.

## 사용자 목표와 확정된 요구

활성 STREAMER/ADMIN이 출처 URL과 글 전문을 입력하면 축구 문맥에 해당하는 원문 영역에 DB 기본정보·기록·경기·이력을 연결한다. 최대 **50,000 Unicode 코드포인트**, 여러 언어와 혼합 언어를 지원 대상으로 둔다. 원문 문자는 유지하고 카드·판단 근거·상태는 한국어로 표시한다.

호버·키보드·터치로 카드에 접근하고 모호한 해석의 후보·근거를 확인한다. 사용자는 대상/조건 선택·수정, 후보 밖 DB 검색, 연결 거부를 할 수 있다. 확인한 판단은 최소 구절·필요 문맥·출처·편집자·변경 이력과 함께 서비스 공통으로 저장하고 다음 분석에 실제 적용한다.

사용자는 **실패 구간을 사용자 조작으로 재시도하는 흐름에 반대**했다. 결과 화면의 **원문과 출처는 읽기 전용**으로 확정했다. 연결 판단과 조회 조건의 수정은 유지한다.

## v6 설계안

1. 본문·URL·선택 기준일 입력. 상대 날짜의 기준이 없으면 추측하지 않고 확인 대상으로 둔다. URL 크롤링 기능을 선제 추가하지 않는다.
2. 원문 버전과 전체 구간 목록을 고정하고 축구 관련성·등장 위치·대상·조회 의도를 추출한다.
3. 정식명·번역명·확정 별칭과 DB 후보·공통 판단을 찾아 문맥을 판별한다. 모델이 만든 ID나 음역 추정을 사실로 확정하지 않는다.
4. 서버가 검증한 지표·시점·대회·집계 조건으로 DB를 조회한다. 생성한 수치·자유 SQL을 그대로 실행하지 않는다.
5. 일시적 구간 실패를 내부에서 복구하고 전체 구간·DB·한국어 표시를 검증한 뒤 결과를 한 번에 공개한다. 미검증 부분 카드를 완료 결과로 제시하지 않는다.
6. 후보 선택·수정·거부의 공통 저장, 버전 충돌·근거 변경·취소를 처리한다. 임시 선택과 저장 성공을 구분한다.

원문 버전·코드포인트 범위·정확한 인용·등장 ID를 기준으로 반복·중첩을 보존하고 화면의 UTF-16 위치로 변환한다. 동일 대상이라도 등장 위치·조회 조건·판단 revision·자료 시각이 다르면 카드 응답을 섞지 않는다.

공통 판단은 유효 범위·충돌·거부·버전·취소 규칙을 갖는다. 같은 표면형을 전역 치환하지 않는다. 다른 사용자의 후속 분석에서 적용 효과와 부적용 반례를 검증한다. 새 판단이나 취소로 근거가 바뀌면 열린 결과에도 오래된 근거임을 알린다.

## 데이터·한국어·장애 상태

조회 사전의 13개 의도는 기본정보, 선수 경기/최근/시즌 기록, 기간 비교, 경기 결과, 상대전적, 순위, 팀 흐름·경기 기록, 소속/감독 관측, 이적, 부상이다. 현재 스냅샷을 과거 사실로 표현하거나 관측일을 부상 발생일로 바꾸지 않는다. 최신 2시즌 안에서도 실제 coverage·NULL·미수집을 구분한다.

DB에 한국어 이름이 없으면 카드 주표시에 한국어 미등록 상태를 표시하고 원문 고유명을 식별용 보조값으로 둔다는 v6 설계가 있다. DB 사실과 모델의 해석 근거를 분리한다.

카드는 자료 있음/일부 자료/자료 없음/조건 확인 필요/자동 복구/복구 소진/근거 변경을 구분한다. 자동 복구 소진은 전체 실패로 알리고 원문을 유지한다. 구간 재시도 버튼을 요구하지 않는다. 전체 작업과 판단 변경 구독은 별도 수명으로 관리하고 polling을 도입하지 않는다.

동일 단위 최초 포함 최대 3회, 재분할 깊이 1단계, 결과 재생 버퍼 10분·본문 없는 종료 표식 24시간은 **초기 설계값**이며 실측으로 확인할 대상이다. 전문은 영속 보관하지 않고 공통 판단·감사만 영속 자료로 둔다. 취소 후 실제 호출 종료와 자원 반환을 구분한다.

## 미확정·평가 조건

최종 뉴스 모델, 검색 조합, 분할 크기·동시성·기한·비용은 미확정이다. 자연어 검색 모델 지정을 뉴스에 자동 적용하지 않는다. 실제 corpus·독립 정답·DB snapshot·이적/부상 적재·지표 coverage·공식 실행 증거 경로가 준비되어야 한다. 필수 연결·금지 오연결·ID/수치/구간과 두 사용자의 공통 판단 흐름을 같은 조건에서 3회 반복한다. 전부 보류하거나 정상 0건만 보여주는 것으로 요구 완료를 대신하지 않는다.
