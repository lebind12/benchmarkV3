## 보존과 삭제

- 기획 원문 545건을 읽어 동일 내용의 중복을 합친 참고본 221건으로 보존했다. 분야별 요약·미결정·출처 목록을 함께 정리했다.
- 원문 파일의 정리 전 SHA-256을 다시 대조한 뒤 삭제했다. 보존 기획은 네 워크트리에 동일하게 복사하고 바이트 단위로 확인했다.
- 개발 소스·테스트·마이그레이션·목업 코드·도구·의존성·환경 파일·생성물·에셋·시드·기존 UI 보존 폴더를 제거했다. 미커밋 코드의 별도 복구본은 만들지 않았다.
- 각 워크트리에는 Markdown 기획/안내와 최소 .gitignore, 기존 .git 메타데이터만 남겼다. API/사전 JSON 계약은 Markdown 예시로 보존했다.
- 구현 제출서·실행 증거·로그·기존 상태 파일은 제거했다. 기획 참고본에 남은 과거 구현 수치는 당시 기록이라고 명시했다.
