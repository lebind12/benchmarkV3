## 문서를 읽는 기준

1. [이번 정리 결정](../decisions/2026-11-09-planning-only-worktrees.md)이 현재 상태와 삭제 범위의 기준이다.
2. 위 요약은 여러 워크트리의 기획을 한곳에서 읽기 위한 정리다. 사용자 확정 사항과 설계 제안·미확정을 구분했다.
3. `reference/`는 과거 기획 원문이다. 당시 구현·승인·검증·배포 표현은 현재 상태로 승계하지 않는다. 홈의 옛 3패널 구성, 폐기한 프리뷰, 뉴스 v1~v5, 검색의 옛 180초 한도는 최신 결정과 구분한다.
4. 기획 원문 545건에서 내용이 같은 문서를 합쳐 221건을 보존했다. [출처·원문 해시 목록](source-index.md)에서 각 워크트리의 문서를 추적할 수 있다. 실행 JSON·스크린샷·테스트 로그를 구현 근거로 재사용하지 않는다.
5. 삭제한 세 워크트리의 기획이 이 기본 저장소의 보존본과 일치함을 확인한 뒤 해당 디렉터리와 Git/Orca 등록을 제거했다. 출처 목록의 이전 워크트리 경로는 역사적 출처다. 원격 저장소·운영 서비스의 상태는 이 로컬 정리 결과와 별개다.
