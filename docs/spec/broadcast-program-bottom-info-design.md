# Broadcast Program Bottom Info Design

작성일: 2026-05-14

상위:
- 요구사항: `docs/features/broadcast-match-program.md`
- 설계 스펙: `docs/features/broadcast-match-program.spec.md`
- 방송 그래픽 리서치: `docs/spec/broadcast-graphics-design-research.md`

## 1. 영역 정의

중계 화면 포함 방송 페이지의 좌측 하단 `22%` 영역은 주요 스탯, 이벤트, 보조정보를 한 장씩 크게 보여주는 방송 그래픽 슬롯이다.

1920x1080 기준 실제 크기:

| 항목 | 값 |
|---|---:|
| 전체 화면 | 1920 x 1080 |
| 좌측 영역 | 1497.6 x 1080 |
| 중계 화면 | 1497.6 x 842.4 |
| 하단 정보 영역 | 1497.6 x 237.6 |

이 영역은 작지 않다. 일반 웹 카드처럼 여러 항목을 빽빽하게 나열하기보다, 한 순간에 하나의 메시지를 강하게 보여주는 lower information band 로 설계한다.

## 2. 핵심 원칙

### 2.1 한 장에는 한 메시지만

하단 영역에 동시에 여러 지표를 넣으면 송출 화면에서 읽히지 않는다. 한 장의 카드가 말하는 내용은 하나여야 한다.

좋은 예:
- `점유율 61% - 39%`
- `63:10 선수 교체`
- `손흥민 2골 · 평점 8.2`
- `최근 10분 왼쪽 하프스페이스 공격 집중`

나쁜 예:
- 점유율, 슈팅, 코너킥, 카드, 패스율을 한 카드에 모두 표시
- 긴 문장형 해설
- 수치와 이벤트를 같은 위계로 섞기

### 2.2 큰 숫자 + 짧은 해석

방송 화면에서는 숫자가 먼저 읽히고, 해석은 그 다음이다.

권장 구조:

```text
┌───────────────────────────────────────────────┐
│ KICKER / CONTEXT                         CODE │
├───────────────┬────────────────┬──────────────┤
│  BIG LEFT     │ TITLE + DETAIL  │  BIG RIGHT   │
└───────────────┴────────────────┴──────────────┘
```

### 2.3 기본은 Vertical Scroller

1차 구현은 위/아래로 한 장씩 넘어가는 vertical scroller 를 기본으로 한다.

이유:
- 움직임이 경기 화면을 과하게 방해하지 않는다.
- 카드 높이가 고정되어 layout shift 가 적다.
- 현재 구현된 `22%` band 와 잘 맞는다.
- 이벤트가 들어왔을 때 해당 카드를 위로 밀어 넣는 연출이 자연스럽다.

Cube flip 은 후보로 남긴다. 리그 패키지감은 강하지만, 숫자/텍스트가 회전 중 순간적으로 읽기 어려울 수 있다.

## 3. 카드 분류

### 3.1 Stat Card

경기 흐름을 수치로 보여준다.

사용 상황:
- 정기 순환
- 특정 지표 변화가 큰 경우
- 하프타임/풀타임 전 스탯 요약

필수 요소:
- kicker: `MATCH CONTROL`, `ATTACK OUTPUT`, `PRESSURE`
- title: `점유율`, `슈팅 흐름`, `패스 성공률`
- left/right big value
- detail 1줄

디자인:
- 좌우 숫자 크기는 가장 크게
- 중앙 제목은 짧고 굵게
- meter 는 점유율처럼 비율 정보가 명확할 때만 사용
- 모든 스탯 카드에 bar 를 붙이지 않는다

### 3.2 Event Card

실제 경기 이벤트를 보여준다.

사용 상황:
- 골
- 카드
- 교체
- VAR
- 하프타임/풀타임

규칙:
- 이벤트 발생 시 일반 스탯 순환보다 우선한다.
- 골/VAR/퇴장처럼 즉시성이 큰 이벤트도 중계화면 위 lower-third 로 노출하지 않는다. 약관 위반 리스크를 피하기 위해 하단 정보 영역에서만 처리한다.
- 교체/경고는 하단 정보 band 만으로 충분할 수 있다.

디자인:
- 왼쪽에 시간
- 중앙에 이벤트 제목과 선수명
- 오른쪽에 팀 코드/현재 스코어/IN-OUT 값
- 아이콘은 크게 하나만 사용. 작은 아이콘 여러 개 금지

### 3.3 Player Spotlight Card

특정 선수의 영향력을 보여준다.

사용 상황:
- 득점 직후
- 멀티골
- 교체 투입 직후
- 평점/스탯이 높은 선수 강조

권장 정보:
- 선수명
- 등번호
- 핵심 수치 1-2개: `2G`, `8.2`, `3 KEY PASSES`
- 아주 짧은 설명

주의:
- 선수 사진을 쓰면 가장 좋지만, 없는 경우 등번호/팀 색상 그래픽으로 충분하다.
- 사진 없는 상태에서 빈 이미지 박스를 크게 두지 않는다.

### 3.4 Tactical Info Card

경기 해석용 보조정보다.

사용 상황:
- 특정 구역 공격 집중
- 최근 10분 점유율 변화
- 압박 라인 상승
- 좌우 측면 공격 편중

권장 구조:
- 왼쪽: 짧은 수치 또는 구역 코드
- 중앙: 전술 제목
- 오른쪽: 상대 수치 또는 방향성

주의:
- 전술 카드는 너무 자주 나오면 해설처럼 보인다.
- 일반 순환에서는 4-5장 중 1장 정도가 적절하다.

## 4. 큐 / 우선순위

하단 band 는 단순 carousel 이 아니라 `고정 순서 + 이벤트 삽입` 큐로 취급한다.

기본 순서:
- 캐러셀은 7초마다 한 장씩 위로 올라간다.
- 내부 큐의 0번째 항목이 현재 표시 카드다.
- 전환이 끝나면 큐를 왼쪽으로 회전시켜 현재 카드가 항상 0번째에 오도록 유지한다.
- 새 이벤트를 발견하면 큐의 2번째 위치, 즉 index `1` 에 삽입한다.
- 최신 이벤트는 현재 카드 바로 다음에 등장해야 한다.
- 새 이벤트를 삽입해도 나머지 큐의 상대 순서는 유지하고 순환은 계속 이어진다.

월드컵 하단 캐러셀 채택안:
- W03 `Host Cities Map Strip`: 월드컵 배너/대기성 대회 정체성 카드
- W01 `Trophy Seal Band`: 점유율, 슈팅 등 기본 스탯 카드
- W08 `Match Ball Orbit`: 골 이벤트 카드
- W04 `Gold Medal Plate`: 현재 최고 평점 플레이어 카드
- W14 `Goal Net Mesh` 변형: 카드, 파울, 오프사이드처럼 짧은 경기 이벤트를 전달하는 Event Mesh Plate

우선순위:

| 우선순위 | 종류 | 노출 시간 |
|---:|---|---:|
| 1 | Goal, Red Card, VAR decision | 7초 |
| 2 | Substitution, Yellow Card | 6초 |
| 3 | Player Spotlight after event | 5초 |
| 4 | Stat delta / Tactical note | 5초 |
| 5 | Regular stat rotation | 5초 |

큐 규칙:
- 새 우선순위 1 이벤트는 큐의 index `1` 에 삽입해 다음 전환에서 바로 보여줄 수 있다.
- 우선순위 2는 현재 루프에 삽입하고, 다음 루프부터 만료 정책에 따라 제거할 수 있다.
- 같은 종류의 stat card 는 기본 순서에서 연속 2장 이상 나오지 않게 한다.
- 이벤트 카드 이후에는 관련 player spotlight 또는 stat delta 를 1장 이어 붙일 수 있다.

## 5. Motion

### 5.1 Vertical Scroller

기본 모션:
- enter: 아래에서 위로 620ms
- hold: 5-7초
- exit: 위로 밀려 나감
- easing: `cubic-bezier(0.22, 0.82, 0.2, 1)`

장점:
- 읽기 쉬움
- 방송 ticker 문법과 잘 맞음
- 이벤트 큐 처리에 적합

### 5.2 Cube Flip

후보 모션:
- 카드 전체가 X축으로 90도 회전하며 다음 면 등장
- stat/player/tactic 처럼 카드 종류가 명확할 때 효과적

위험:
- 긴 한글 텍스트가 회전 중 깨져 보일 수 있음
- 숫자 중심 카드에는 좋지만 이벤트 상세에는 과할 수 있음

권장:
- `transition=cube` query 로 비교 후보만 제공
- 기본값은 vertical

## 6. 리그별 시각 차이

| 리그 | Band 형태 | Motion 톤 |
|---|---|---|
| Premier League | capsule + magenta/cyan split | 빠른 vertical slide |
| Champions League | dark rail + light streak | 부드러운 glide |
| Europa League | angled black/orange strip | 약한 skew slide |
| Carabao Cup | ticket/stamp band | 짧은 snap |
| FA Cup | navy/red/gold plate | classic wipe |
| World Cup 2026 | ribbon + flag badge | ribbon reveal |

색상은 기존 테마를 따르되, 하단 band 는 영상과 맞닿기 때문에 배경 대비를 강하게 잡는다.

## 7. 1차 구현 평가 기준

다음 조건을 만족하면 1차 목업으로 충분하다.

- 1920x1080 에서 하단 영역이 정확히 22% 높이를 유지한다.
- 한 카드에 핵심 메시지가 1개만 보인다.
- 3초 안에 숫자/이벤트 종류를 읽을 수 있다.
- 영상 feed 를 가리는 UI 가 전혀 없다.
- 우측 채팅/캐릭터 영역과 시각적으로 충돌하지 않는다.
- 우측 채팅/캐릭터 영역은 `#00B140` 크로마키 면으로 비워진다.
- 리그별 색상/형태 차이가 최소 1개 이상 보인다.
