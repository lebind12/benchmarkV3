# 서비스 포트폴리오 근거와 영상 기획

서비스 전체를 대상으로 계획 확정 및 주요 이정표마다 갱신한다. 병합 단위 이력서 문구가 아니다.

- service_id / 서비스명:
- 대상 독자와 핵심 메시지 (한 문장):
- 결과물 상태: 근거 수집 / 스토리보드 / 제작 / 렌더 검증
- 운영자와 정할 영상 길이·화면 비율·언어·내레이션·배포 형식:

| 장면 | 전달할 내용 | 근거 경로·출처 | 상태와 시점 |
|---|---|---|---|
| 문제 | 사용자와 해결할 문제 | | 계획 |
| 시연 | 실제 사용자 흐름 | | 구현 / 테스트 |
| 기술적 근거 | 대안과 선택 이유 | | 결정 |
| 검증 결과 | 실제 시험 또는 측정 결과와 한계 | | 테스트 / 측정 |
| 사람의 기여 | 사람의 판단·작업과 AI의 역할 | | 확인된 사실 |

- 영상 구성과 내레이션:
- 계획·구현·테스트·배포·측정의 구분:
- 확인되지 않은 주장과 수치: 제외하거나 가설로 명시
- Notion 저장: 목적지와 범위를 승인받은 경우에만 선택적으로 수행

## 제작 및 검증

- 실제 시연 화면과 개념도·재구성 장면의 구분:
- 사용할 렌더링 도구·소스 파일·에셋 경로·사용 권한:
- 데이터 흐름 애니메이션이 실제 구현과 일치하는 근거:
- 가독성·장면 속도·내레이션 동기화·비밀정보 노출 점검:
- 최종 렌더 파일·해상도·길이·재생 확인:
- 이력서 요약: 위 서비스 전체 사례를 근거로 필요한 경우에만 압축

미정 형식이나 실제로 제작하지 않은 영상은 완료로 표시하지 않는다. 머지 횟수나 AI가 작성한 코드량을 사용자의 사업 성과로 대체하지 않는다.
