# World Cup Extracted Asset Pool

생성된 월드컵 하단 바 시안에서 캐릭터, 아이콘, 장식 모티프를 사각 PNG 클립으로 추출한 후보 풀이다.

## 구조

- `characters/`: 스트리머 캐릭터풍, 팬캐릭터/마스코트풍, 심판/응원/VAR/교체 등 캐릭터 클립
- `icons/`: 골, VAR, 교체, 카드, 휘슬, 공, 스탯 아이콘 클립
- `motifs/`: 메달, 경기장, 카운트다운, 전술판, 골망, 스탯 바/프레임 클립
- `review/extracted-assets-overview.png`: 전체 후보를 빠르게 보는 리뷰 시트
- `manifest.json`: 각 클립의 원본 이미지와 crop box 정보

## 사용 원칙

- 현재 클립은 다양성 확보용 1차 추출물이다. 대부분 배경이 포함된 사각 PNG이므로, 최종 UI 에셋으로 쓰기 전 투명화/리드로잉/재생성이 필요할 수 있다.
- 공식 로고, 팀 엠블럼, 실제 국기 대체용으로 쓰지 않는다.
- 하단 캐러셀에 직접 넣을 때는 텍스트/수치 안전영역을 침범하지 않는 작은 보조 장식으로만 사용한다.
- 채택 후보는 `assets/generated/world-cup/bottom-bar/final/` 같은 별도 폴더로 정제본을 만들어 관리한다.
